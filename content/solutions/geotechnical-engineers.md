  - type: faq
    title: Questions geotechnical engineers ask us
    note: If you have further questions, please reach out via our Contact page.
    cta: { label: Contact us, href: /get-started }
    items:
      - q: What input data does the system need?
        a: >-
          Standard borehole logs and CPT data in common formats. If your data is in PDF
          or spreadsheet form, we can process that too. The more investigation points
          you have, the more accurate the statistical soil model becomes, but the system
          works with as few as three boreholes.
      - q: How much material can realistically be saved?
        a: >-
          It depends on the project, but typical savings range from 15% to 30% on pile
          concrete and steel compared to conventional conservative designs. The savings
          come from using probabilistic soil models instead of worst case assumptions,
          which allows you to design closer to actual site conditions while maintaining
          the same safety level.
      - q: Does this replace the geotechnical engineer?
        a: >-
          No. This is a tool for geotechnical engineers, not a replacement. It handles
          the computational heavy lifting so the engineer can focus on interpreting
          results, applying judgment, and making decisions. The final design is always
          reviewed and approved by a qualified professional.
      - q: Which pile types does the system support?
        a: >-
          Bored piles, driven piles, CFA piles, and micropiles. The optimization
          considers type specific installation effects and resistance models. If you
          work with a pile type that is not listed, contact us and we can discuss adding
          it.
      - q: How does the CO2 calculation work?
        a: >-
          We use established emission factors for concrete, steel, and installation
          processes based on published lifecycle data. The system calculates the embodied
          carbon for each design variant and presents the results alongside structural
          performance and cost. This allows direct comparison of design alternatives on
          all three dimensions.
      - q: Can we use this for projects outside of Germany?
        a: >-
          Yes. The Eurocode framework applies across Europe, and national annexes can be
          configured for different countries. We currently support the German, Austrian,
          and Dutch national annexes, with more being added. If your country is not yet
          supported, we can add the relevant annex within a few weeks.
