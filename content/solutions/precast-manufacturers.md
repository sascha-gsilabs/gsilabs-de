  - type: faq
    title: Questions precast plants ask us
    note: If you have further questions, please reach out via our Contact page.
    cta: { label: Contact us, href: /get-started }
    items:
      - q: What input format does the system need?
        a: >-
          The system works with IFC models and native BIM formats from Revit, Tekla, and
          Allplan. If you receive architectural plans in 2D, we can discuss a workflow to
          convert them into a usable 3D model as a first step.
      - q: How long does it take to process a new building project?
        a: >-
          Once your production rules are defined, a typical residential project with 200
          to 400 elements can be modularized and have initial drawings generated within a
          few days. Manual processing of the same scope typically takes three to four
          weeks.
      - q: Can the system handle non-standard element types?
        a: >-
          Yes. The rule engine is flexible enough to handle special elements like balcony
          slabs, staircase units, sandwich panels, and custom facade elements. If an
          element falls outside the standard rules, the system flags it for manual review
          rather than producing incorrect output.
      - q: Does this work with our existing production equipment?
        a: >-
          The system exports machine files in the formats your equipment requires. We
          support unitechnik, PXML, and can add support for proprietary formats. Before
          deployment, we test the output files directly on your machines to make sure they
          work on the first try.
      - q: What happens if the architectural model changes mid project?
        a: >-
          The system can reprocess an updated model and identify which elements have
          changed. Only affected elements are regenerated. Unchanged elements keep their
          existing drawings and approvals, so you do not lose work when architects issue
          revisions.
      - q: How does quality control work?
        a: >-
          Every generated drawing goes through a review step before it is released for
          production. The system also runs automated checks for clashes, reinforcement
          coverage, and producibility violations. Engineers approve the final output, not
          the machine.
