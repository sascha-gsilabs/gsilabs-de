  - type: faq
    tone: void
    title: Kostenprognose, die mit jedem abgeschlossenen Projekt besser wird.
    note: Wenn Sie weitere Fragen haben, melden Sie sich gern über unser Kontaktformular.
    cta: { label: Kontakt aufnehmen, href: /get-started }
    items:
      - q: Welche Daten braucht das System für den Start?
        a: >-
          Mindestens historische Kostendaten aus Ihren abgeschlossenen Projekten in
          irgendeiner strukturierten Form. Tabellen, ERP-Exporte oder auch eingescannte
          Schlussrechnungen. Je mehr Projekte Sie liefern, desto genauer wird das Modell.
          Öffentlich verfügbare Marktdaten und Kostenindizes binden wir automatisch ein.
      - q: Wie genau sind die Schätzungen?
        a: >-
          Die Genauigkeit hängt von Qualität und Menge Ihrer historischen Daten ab. Mit
          einem Portfolio von zehn oder mehr vergleichbaren abgeschlossenen Projekten
          erreicht das System in der Machbarkeitsphase typischerweise Schätzungen, die 5 %
          bis 10 % von den tatsächlichen Endkosten abweichen. Das verbessert sich über die
          Zeit, wenn weitere Projekte abgeschlossen und zurückgespielt werden.
      - q: Ersetzt das unsere Kostenplaner?
        a: >-
          Es ist als Ergänzung Ihrer Kostenplaner gedacht, nicht als Ersatz. Das System
          liefert die datengetriebene Basisschätzung, damit sich Ihre Fachleute auf die
          Punkte konzentrieren können, die Urteil, Marktkenntnis und Verhandlung
          erfordern. Viele unserer Kunden erzeugen damit in Minuten eine erste Schätzung
          und lassen sie anschließend von ihren Kostenplanern schärfen.
      - q: Funktioniert das für unterschiedliche Nutzungsarten?
        a: >-
          Ja. Das System unterstützt Wohnungsbau, Gewerbe, gemischte Nutzung und Industrie.
          Jede Nutzungsart hat ihr eigenes Kostenmodell auf Basis passender Vergleichswerte.
          Wenn Sie über mehrere Nutzungsarten hinweg entwickeln, führt das System getrennte
          Modelle und wählt anhand der Projektparameter automatisch das richtige.
      - q: Wie geht es mit Preisänderungen am Markt um?
        a: >-
          Das System aktualisiert seine Annahmen zu Material- und Lohnkosten regelmäßig
          anhand von Marktindexdaten. Wenn Sie eine Schätzung erstellen, verwendet es die
          aktuellsten verfügbaren Preise. Für Projekte mit langem Planungshorizont kann das
          System Preissteigerungsszenarien auf Basis historischer Preisentwicklungen
          abbilden.
      - q: Können wir das für Projekte in anderen Regionen nutzen?
        a: >-
          Ja. Das System unterstützt regionale Kostenmodelle, die örtliche Lohnkosten,
          Materialverfügbarkeit, regulatorische Kosten und Marktbedingungen abbilden.
          Derzeit decken wir den deutschen Markt im Detail ab, weitere europäische Märkte
          kommen hinzu. Jede Region hat eigene Vergleichswerte und Kostentreiber.
